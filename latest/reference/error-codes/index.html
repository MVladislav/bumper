Error Codes¶

Robots report errors as numeric codes. This page documents the codes Bumper currently maps; unrecognized numeric codes remain visible without an invented description.

Code meanings can vary by robot family. The sections below group codes by the component or fault area suggested by their names and available reference data; they do not imply that every code applies to every robot.

Code reference¶

The mapping is maintained in bumper/utils/device_errors.py:

from bumper.utils.device_errors import describe

describe(312)

This returns Auto empty station: dust bag full (312). The app-compatible api/pim/eventdetail.html?errcode=... page uses the same mapping. Guidance is curated for some codes; other codes receive safe, general recommendations that are identified as generic rather than official Ecovacs instructions.
